# 🌦️ Real-Time Weather Application

A clean, responsive, and lightweight Weather Web Application built using **HTML5**, **CSS3**, and **Vanilla JavaScript**. It fetches real-time meteorological data for any city across the globe using the **OpenWeatherMap REST API**.

---

## 🚀 Live Demo

Check out the live version of the project here:  
👉 **[Live Weather App](https://akashtomar75.github.io/weather_app/)**

---

## 📌 Features

- **Real-Time Data:** Fetches up-to-date temperature, weather condition, humidity, and wind speed.
- **Search Functionality:** Instant weather search via city name (supports both Search button and `Enter` key).
- **Graceful Error Handling:** Displays clean alerts if the city name is invalid or not found.
- **Modern UI:** Styled with gradient colors, smooth cards, and responsive layout for both mobile and desktop screens.

---

## 🛠️ Tech Stack

- **HTML5:** Semantic layout and structure.
- **CSS3:** Modern styling, Flexbox layout, and gradient themes.
- **JavaScript (ES6):** Asynchronous programming using `Fetch API` and `async/await`.
- **API:** [OpenWeatherMap API](https://openweathermap.org/)
